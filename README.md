# Subnautica: Below Zero Thunder Kit Mods
## Introduction

This repository contains all of my Subnautica: Below Zero [ThunderKit](https://github.com/PassivePicasso/ThunderKit) Mods in a single Unity 2019.4.36f1 project. It includes the mods themselves, and high level ThunderKit settings and extensions, as well as Unity helpers and utilities.

I also maintain an equivalent [Subnautica repository](https://github.com/mroshaw/SubnauticaThunderKitMods), with ThunderKit mods for the original  Subnautica game.

You can find non-ThunderKit Subnautica mods in my [Subnautica Mods](https://github.com/mroshaw/SubnauticaMods) repository, though these will be migrated over time to this new repo.

## Mods

- [Aqua Eclipse Now BZ](https://github.com/mroshaw/BelowZeroThunderKitMods/tree/main/Assets/Mods/AquaEclipseNow_BZ) - adds new console commands to force a solar eclipse to occur.
- Auto Locker Labels BZ - dynamic labels for lockers, based on their contents.
- [Booster Tank Speed Mod BZ](https://github.com/mroshaw/BelowZeroThunderKitMods/tree/main/Assets/Mods/BoosterTankSpeedModifier_BZ) - adds a configurable modifier to alter the speed of the Suit Booster Tank.
- [More Aquariums BZ](https://github.com/mroshaw/BelowZeroThunderKitMods/tree/main/Assets/Mods/MoreAquariums_BZ) - adds new buildable aquariums to the habitat builder, and a custom fish movement component.
- [Prawn Suit Repair and Charge BZ](https://github.com/mroshaw/BelowZeroThunderKitMods/tree/main/Assets/Mods/PrawnRepairAndCharge_BZ) - the Prawn Suit will now be repaired and recharged when docked.
- [Sea Glide Speed Mod BZ](https://github.com/mroshaw/BelowZeroThunderKitMods/tree/main/Assets/Mods/SeaGlideSpeedMod_BZ) - adds a configurable modifier to alter the speed of the Sea Slide.
- [Sea Truck Fish Scoop BZ](https://github.com/mroshaw/BelowZeroThunderKitMods/tree/main/Assets/Mods/SeaTruckFishScoop_BZ) - adds a Fish Scoop to the Sea Truck, causing fish to be sucked into aquariums, rather than being squished.
- [Sea Truck Recall BZ](https://github.com/mroshaw/BelowZeroThunderKitMods/tree/main/Assets/Mods/SeaTruckRecall_BZ) - adds a new UI to the Sea Truck dock, and an autopilot component to pilot the nearest Sea Truck back to base.
- [Sea Truck Speed Modifier BZ](https://github.com/mroshaw/BelowZeroThunderKitMods/tree/main/Assets/Mods/SeaTruckSpeedModifier_BZ) - adds a configurable modifier to alter the speed of the Sea Truck.
- [Startup Commands BZ](https://github.com/mroshaw/BelowZeroThunderKitMods/tree/main/Assets/Mods/StartupCommands_BZ) - allow players to configure a list of console commands to run every time the game is started.
- [Subnautica Cheater BZ](https://github.com/mroshaw/BelowZeroThunderKitMods/tree/main/Assets/Mods/SubnauticaCheater_BZ) - adds cheats for infinite oxygen and health, mainly for use in debugging and testing other mods.
- [Subnautica Pets BZ](https://github.com/mroshaw/BelowZeroThunderKitMods/tree/main/Assets/Mods/SubnauticaPets_BZ) - adds craftable creatures to the game via new game lore, fragments, resources and base parts.
- [Tame Creatures BZ](https://github.com/mroshaw/BelowZeroThunderKitMods/tree/main/Assets/Mods/TameCreatures_BZ) - selectively remove aggressive behaviours from various creatures in the game.
- [Vehicle Enhancements BZ](https://github.com/mroshaw/BelowZeroThunderKitMods/tree/main/Assets/Mods/VehicleEnhancements_BZ) - adds configurable HUD elements, such as a speedometer and HSI, to all vehicles in the game.

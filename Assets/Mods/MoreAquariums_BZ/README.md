# More Aquariums

Bored of the limit options available for showing off your fish? Then More Aquariums is the mod for you!

## Features

This mod adds new items to the habitat builder once you've unlocked the basic "Aquarium" interior module.

- **Double Aquarium** - A double-length aquarium, capable of displaying twice as many fish as the standard aquarium.
- **Corner Aquarium** - Ideal for gracing the corner of a large room, this aquarium also has capacity for 16 fish.
- **Desk Aquarium** - Perfect for placing on a desk or shelf, this miniature aquarium holds two fish.
- **Spherical Aquarium** - The perfect centrepiece for your room! This sphere-shaped aquarium holds 16 fish and looks great in the middle of a base room.
- **Observatory Aquarium** - A showcase for your base! This external base piece holds up to 20 fish and is a stunning addition to any undersea home!

## Options

Go to Options > Mod Options, and you can tweak some features of the mod:

- **Use Observatory Flood Water** - if enabled, adds a subtle blue water effect to Observatory Aquariums. If you don't like this, you can turn it off
- **Bubble Audio** - custom aquariums have an ambient bubble sound that you can turn off if you find it annoying.
- **Detailed Logging** - only enable this if you have an issue and want to provide useful logging when reporting a bug.

Also available for Below Zero﻿!

## Installation and Dependencies

> ***IMPORTANT!** This mod uses **BepInEx** ﻿﻿and **Nautilus**﻿﻿. You **must** install the latest versions of these to use this mod. As the 2025 patch broke a lot of mods, you must use **Nautilus version 1.0.0-pre.50** or later.*

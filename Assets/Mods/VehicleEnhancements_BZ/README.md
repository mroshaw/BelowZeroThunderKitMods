# Vehicle Enhancements BZ

This mod adds some super-cool enhancements to the standard vehicles in Below Zero: the Seatruck, the Prawn Suit and the Snow Fox. The list of enhancements is growing and will continue to grow with your feedback and suggestions!

*Previously published as Seatruck Enhancements BZ! Please uninstall the old mod before installing this new one!*

## Features

### Available in all vehicles

- A **speedometer** in the in-game HUD UI showing forward speed in meters per second.
- A Vertical Speed Indicator (VSI) showing the rate of ascent or descent in meters per second.
- A **Horizontal Situation Indicator (HSI)** showing the pitch and roll of the vehicle in degrees.
- A **configurable reversing sound** so that ocean inhabitants can get out of the way as you're backing up.
- A **time-of-day indicator** showing the passage of day into night, alongside a digital clock showing the current game time.
- A **weather indicator** showing the current weather conditions outside - useful if you're diving down into the depths and want to know what the weather's like on the surface!

### Available in the Seatruck only

- A **reversing camera** so that you can back up the Seatruck safely.
- An **ability to build anything anywhere** within the Seatruck!

## User Guide

The mod works entirely based on the settings in mod options, there's no "in-game" controls or changes to worry about.

A note on "Build inside": if you build objects that consume power, such as a battery charger, inside the Seatruck, that object will consume power from the Seatruck. If you subsequently toggle off the "Build inside" option, objects that you've built will remain where they are, but will no longer consume power from the Seatruck.

## Options

### Per vehicle options

You can toggle features on or off per vehicle via the Options > Mods menu:

- **Speedometer** - toggle on to enable the speedometer and VSI enhancement.
- **HSI** - toggle on to enable the Horizontal Situation Indicator, showing the pitch and roll of the vehicle.
- **Time and weather** - toggle on to enable the time of day and weather indicators on the left side of the HUD.
- **Reversing voice** - select a spoken voice audio clip to play when the vehicle is reversing. Select "None" to disable reversing voice audio.
- **Reversing beeps** - toggle on to enable a "beep beep beep" audio when the vehicle is reversing. Can be used in addition to the reversing voice option.
- **Reversing camera (*Seatruck only*)** - toggle on to enable the reversing camera on the Seatruck.

### Global options

There are also some global settings that effect all vehicles:

- **Reversing audio volume** - use to increase or decrease the volume of the reversing audio.
- **Detailed logging** - only enable this if you have an issue and want to provide useful logging when reporting a bug.

## Installation and Dependencies

> ***IMPORTANT!** This mod uses **BepInEx** ﻿﻿and **Nautilus**﻿﻿. You **must** install the latest versions of these to use this mod!*

> ***IMPORTANT!** If you have the old **'Seatruck Enhancements BZ**' mod installed, **you must remove it before installing this new mod**! You'll get a warning displayed when you launch the game if this is the case, but the enhanced features won't be available until you remove the old mod.*

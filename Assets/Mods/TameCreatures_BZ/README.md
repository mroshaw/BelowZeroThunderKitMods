# **Tame Creatures BZ**

Tired of being harassed by pesky Squid Sharks? Cryptosuchus driving you crazy? Too scared to face a Leviathan? Then this is the mod for you!

## Features

With this mod you can toggle aggression towards the player on or off for most of the aggressive creatures in the game. Bored of being bothered by Brinewings? Touch the tame toggle and you're as good as gold!

## User Guide

All functionality for the mod is provided through mod options.

## Options

Go into Options > Mods and find the section labelled "Tame Creatures". Here you can configure the mod. It currently supports taming the following creatures:

- Alien Robots
- Brinewings
- Brute Sharks
- Chelicerates
- Cryptosuchus
- Ice Worm (scripted events will still trigger)
- Lily Paddlers
- Rock Punchers
- Shadow Leviathans
- Snow Stalkers
- Squidsharks
- Symbiotes

## Installation and Dependencies

> ***IMPORTANT!** This mod uses **BepInEx** ﻿﻿and **Nautilus**﻿﻿. You **must** install the latest versions of these to use this mod. As the 2025 patch broke a lot of mods, you must use **Nautilus version 1.0.0-pre.50** or later.*
